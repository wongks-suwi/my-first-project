# Pomodoro · London Christmas

แอป Pomodoro ภาษาไทย ธีมคริสต์มาสลอนดอน ทำงานออฟไลน์ได้ 100% ไม่มีโฆษณา และไม่เรียกไฟล์จากอินเทอร์เน็ตเลย
(ไม่มี CDN, ไม่โหลดฟอนต์, ภาพทั้งหมดวาดเองด้วย SVG/CSS)

## ฟีเจอร์
- จับเวลา: โฟกัส 25 / พักสั้น 5 / พักยาว 15 (ทุก 4 รอบ) ปรับได้ มีเริ่ม/หยุด/ข้าม/รีเซ็ต นับรอบและสถิติ 7 วัน เก็บในเครื่อง
- เครื่องเล่นเพลงของคุณ: เพิ่มไฟล์ mp3/m4a/wav จากเครื่อง เก็บใน IndexedDB เล่นออฟไลน์ได้ เรียง/ลบ/วน/สุ่ม/ปรับเสียง
  และเลือกให้เพลงเริ่มตอนโฟกัส หยุดตอนพักได้
- เสียงกระดิ่งจบรอบสร้างด้วย Web Audio API (ไม่มีไฟล์เสียง)
- PWA: ติดตั้งลงหน้าจอโฮมได้ ใช้งานออฟไลน์ด้วย service worker

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า + ฉาก SVG |
| `style.css` | ธีม แอนิเมชัน กระจกฝ้า |
| `app.js` | ตัวจับเวลา สถิติ เพลง เสียงกระดิ่ง |
| `sw.js` | Service worker (แคชไฟล์ทั้งหมด) |
| `manifest.json`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | ข้อมูลติดตั้งแอป |

## วิธีรัน
service worker ทำงานได้เฉพาะ `https://` หรือ `localhost` (เปิดไฟล์ด้วยการดับเบิลคลิกจะใช้ฟีเจอร์ออฟไลน์ไม่ได้)

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

ถ้าแก้ไฟล์ของแอป ให้เปลี่ยนเลข `VERSION` ใน `sw.js` เพื่อให้แคชเก่าถูกล้าง

ติดตั้งบน iPhone: เปิดผ่าน Safari → ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”
